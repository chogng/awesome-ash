# 原生桌面与 App Server 的连接边界

当前 Desktop 入口负责打开系统窗口。以下是接入首个后端工作流时的职责分工。 [Desktop 架构](desktop-architecture.md)

```text
工作台视图 → 产品领域接口 → 协议适配 → ash-app-server-client → App Server
```

- **工作台视图**持有焦点、草稿和选择等交互状态，通过领域接口读取数据、订阅变化和提交意图。Ash GPUI 和 Ash UI Kit 接收视图数据及动作回调。
- **产品领域接口**为调用方提供业务操作、状态和错误；协议适配集中转换生成的请求、响应和通知。多个领域接口复用宿主提供的连接。
- **桌面宿主**装配并管理连接，负责启动、取消、重连和关闭。桌面通过共享 App Server 接入后台，Rust 客户端提供初始化、请求配对、通知和关闭；本地运行包的进程入口是独立的 `ash-app-server`。 [Rust 客户端](../crates/app-server-client/README.md)
- **App Server 和后端领域**负责权限、执行及持久化。Session、Thread、Turn 和审批状态从后端投影到界面。 [App Server API](app-server-api.md#唯一外部门禁)

连接恢复后重新获取领域快照并建立订阅。结果未知的修改请求由领域契约决定能否安全重试。窗口关闭时释放窗口订阅和关联任务，共用的后台进程由其生命周期所有者管理。连接和文件 I/O 在 UI 事件循环之外执行。

## 绘制与连接延迟

按键、输入法、滚动、选区和撤销由桌面进程中的界面及编辑器模型处理。Ash GPUI 直接使用本地布局和绘制数据提交 GPU 帧。保存、搜索和提交 Agent 任务等需要共享后端的操作走异步请求，返回结果和流式通知更新对应的视图。

桌面创建窗口和启动本地交互时，并行取得后端连接。每条连接建立后先做一次 `initialize`，校验版本、协议和能力。后续请求复用已就绪的连接，重连时重新初始化。需要后端数据的视图在等待时显示连接状态。 [App Server 初始化](app-server-api.md#4-初始化)

### 首个 Chat 切片

1. 桌面启动时创建窗口并启动连接任务。任务通过 `AppServerSession::start_stdio` 连接同一 profile 的托管 App Server，复用 `ash-app-server-daemon connect` 的进程选择与启动逻辑。连接任务持有会话及其关闭责任，通过窗口事件循环发布就绪、失败和后续领域更新。 [托管 App Server](../crates/app-server-daemon/README.md)
2. 有上次选择的 Session 和 Thread 时，连接就绪后直接用 `session/thread/subscribe` 订阅该 Thread，并随请求取得最近一页正文快照。会话目录独立加载。上次选择属于 GUI 导航状态，正文、执行状态和审批以服务端返回为准。 [Thread 快照和分页](app-server-api.md#7-thread-与-turn)
3. 首个已验证的快照到达后打开恢复的 Chat 并启用依赖后台的操作。等待期间本地输入继续可用。关闭窗口时释放所属订阅，连接任务结束时关闭其会话，共享后台由 daemon 管理。

### 冷启动对照

主指标为从启动桌面到上次 Chat 可交互。另记窗口首帧、进程取得、连接 `initialize` 完成、首份快照和首份快照上屏的时刻。用同一构建类型和相同隔离 profile 分别测量后台已停止、后台可复用和首次使用的场景。首个真实切片还应验证连接延迟时的本地输入、恢复失败提示及退出清理。

后端探针可先对照直接 stdio 和现有进程内测试模式，复用同一 App Server 分发器、`initialize` 和有界快照。两种现有实现均编解码 JSON。对照包含子进程启动、传输和宿主初始化差异。托管路径另量 daemon 取得和复用的开销。若实测表明进程边界显著推迟 Chat 可交互，再评估桌面是否需要生产级的进程内模式，并验证后台任务寿命与故障隔离。 [App Server 传输](app-server-api.md#3-传输)

macOS arm64 的后端探针使用 `ci-test` 构建，恢复同一份仅含一个空 Chat 的隔离 profile。去掉每组一次预热后，各五次的启动到快照中位数为直接 stdio 55 ms、保留后台队列的进程内入口 1054 ms。连接就绪后两组的快照请求中位数都约为 0.5 ms。探针覆盖现有后端入口，桌面上屏和 daemon 复用仍需在原生切片中测量。
